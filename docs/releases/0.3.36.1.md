Hydra 0.3.36 with Omarchy support, built from `luccast/omarchy`. This build updates itself from this fork's releases.

- **Hyprland (Wayland) master** (upstream PR #14): input from evdev, cursor and monitors from Hyprland's IPC, and the clipboard through wl-clipboard. Your user must be in the `input` group.
- **Unplugged input devices** (upstream PR #15): a device that is unplugged or reconnects no longer spins Hydra at full CPU, and devices plugged in later are picked up.

Everything else is upstream 0.3.36. A Mac or Windows machine can run either this build or upstream's.
